## Install Guide

### Windows

Run the [windows install script](../install/windows.ps1) to install kebab-gui onto your windows device. When you are ready to boot, simply run:

```powershell
python boot.py
```

### Linux

Run the [linux install script](../install/linux.sh) to install kebab-gui onto your linux device. When you are ready to boot, simply run:

```bash
python boot.py
```

### Mac

Run the [mac install script](../install/mac.sh) to install kebab-gui onto your mac device. When you are ready to boot, simply run:

```bash
python boot.py
```

Read the [README](../README) to find out more.

For an OS-like VM setup that auto-boots into kebab-gui fullscreen, see [VM Mode](VM.md).
