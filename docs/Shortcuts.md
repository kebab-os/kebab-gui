# kebabOS Keyboard Shortcuts

This document lists all available keyboard shortcuts in kebabOS.

## Quick App Launch

| Shortcut | Action |
|----------|--------|
| **Ctrl+Alt+C** | Open Calculator |
| **Ctrl+Alt+B** | Open Browser |
| **Ctrl+Alt+F** | Open Files |
| **Ctrl+Alt+N** | Open Notebook |
| **Ctrl+Alt+T** | Open Terminal |

## Window Management

| Shortcut | Action |
|----------|--------|
| **Alt+Tab** | Cycle through open windows (backward) |
| **Ctrl+Shift+Tab** | Cycle through open windows (forward) |
| **Ctrl+Alt+W** | Close active window |
| **Ctrl+Alt+Shift+Esc** | Force quit active window |
| **Ctrl+Alt+Shift+M** | Toggle fullscreen for active window |
| **Ctrl+Alt+P** | Focus previous window |
| **Ctrl+Alt+O** | Focus next window |

## Desktop & System

| Shortcut | Action |
|----------|--------|
| **Ctrl+Alt+M** | Minimize all windows (hide desktop) |
| **Ctrl+Alt+D** | Show desktop (close all windows) |
| **Ctrl+Alt+Delete** | System action (close all windows) |
| **Ctrl+Alt+A** | Open all applications (populate desktop) |
| **Ctrl+Alt+L** | Lock/Logout |
| **Ctrl+Alt+Shift+L** | Logout (explicit) |

## Start Menu & Navigation

| Shortcut | Action |
|----------|--------|
| **Ctrl+Alt** (any modifier key) | Toggle Start Menu |
| **Escape** | Close Start Menu |

## System Control

| Shortcut | Action |
|----------|--------|
| **Ctrl+Shift+X** | Shutdown kebabOS |

---

## Shortcut Categories

### Application Launcher (Ctrl+Alt)
- Use Ctrl+Alt + a letter to quickly launch applications
- **C**alculator, **B**rowser, **F**iles, **N**otebook

### Window Navigation (Alt+Tab)
- Alt+Tab cycles backward through open windows
- Ctrl+Shift+Tab cycles forward through open windows
- Useful for quickly switching between multiple applications

### Desktop Management (Ctrl+Alt)
- **D** = Show Desktop
- **M** = Minimize/Hide All Windows
- **A** = Open All Apps

### Logout & Exit
- Ctrl+Alt+L to logout
- Ctrl+Shift+X to shutdown the entire system

---

## Tips & Tricks

1. **Quick App Switching**: Use Alt+Tab to rapidly switch between your open applications
2. **One-Handed Access**: Most shortcuts use Ctrl+Alt, making them easy to access with one hand
3. **Desktop Cleanup**: Press Ctrl+Alt+D to quickly minimize all windows and view the desktop
4. **Force Close**: If an app is unresponsive, use Ctrl+Alt+Shift+Esc to force close it
5. **Window Cycling**: Use Ctrl+Alt+P and Ctrl+Alt+O to manually cycle through windows

---

## Compatibility Notes

- These shortcuts are designed to not conflict with Windows system shortcuts
- Safe combinations: Ctrl+Alt, Alt+Tab, Ctrl+Shift
- Shortcuts work system-wide in kebabOS, even when the Start Menu is closed
